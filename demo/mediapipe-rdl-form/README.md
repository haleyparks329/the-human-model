# MediaPipe RDL Form Demo

**Status:** Experimental

This folder preserves a screen recording from an early local movement-analysis prototype for Romanian deadlift review.

## Recording

- [`rdl-form-mediapipe-overlay-demo.mov`](rdl-form-mediapipe-overlay-demo.mov)

The recording shows a pose overlay and movement chart alongside an RDL video. It demonstrates one exploratory path for turning ordinary training footage into inspectable evidence.

## What it demonstrates

- pose tracking applied to one RDL recording;
- a visual overlay for human review;
- a charted movement signal;
- an early step toward rep-level analysis.

## Limits

This is a historical experiment, not a generalized exercise coach, validated biomechanical assessment, or finished correction system. It does not establish current private implementation status. Any reuse of the recording requires a fresh publication and metadata review under the [asset policy](../../assets/asset-manifest.md).
