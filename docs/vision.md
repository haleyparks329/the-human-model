# Vision

The long-term product is not a watch, dashboard, chatbot, report, or score. It is a personalized model that can preserve evidence, represent uncertainty, learn from corrections, form cautious hypotheses, and evaluate those hypotheses against later outcomes.

Bodybuilding is the first research environment because it creates repeated observations, interventions, and feedback. The broader question applies anywhere software must understand change in one person without pretending a population average is a personal truth.

The public vision is intentionally about the problem, model loop, human review, and evaluation. It does not specify production data sources, schemas, interfaces, prompts, calibration, routing, or runtime composition.
